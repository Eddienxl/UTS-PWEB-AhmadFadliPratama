# Project Overview

This project is a modified version of the Quran application, originally created by Muhammad Najib Saragih. The goal is to provide a unique user experience while maintaining the core functionalities of the original application.

## Features
- User-friendly interface
- Quran reading capabilities
- Bookmarking functionality
- Juz and Surah navigation

## Installation
To install the project, clone the repository and run the following command:

```bash
npm install
```

## Usage
To start the application, run:

```bash
npm start
